# UPS Emulator

Эмулятор SNMP-совместимого ИБП (UPS) с поддержкой SNMP v1/v2c, BER-кодирования, конфигурации моделей через INI-файл и модульной архитектурой. Проект предназначен для разработки и тестирования систем мониторинга без необходимости подключения реального оборудования.

## Возможности

- Обработка SNMP GET-запросов (v1 и v2c).
- Кодирование и декодирование BER/ASN.1.
- Модульная структура для поддержки различных моделей UPS (APC, INELT и др.).
- Загрузка конфигураций моделей из файла `ups_models.ini`.
- Хранилище параметров UPS с типами, значениями и правилами валидации.
- Встроенный эмулятор поведения UPS.
- Полный набор модульных тестов (GoogleTest).
- Инструменты для анализа покрытия тестами.

## Архитектура проекта

Проект состоит из нескольких логических модулей:

```
src/
  main.cpp                      — точка входа
  emulator/                     — логика эмуляции UPS
  snmp/                         — SNMP-агент, кодек и BER-энкодер
  ups/                          — модели UPS, параметры, OID, value-sets
  utils/                        — утилиты (fs_utils, string_utils, ini_section_reader)
tests/
  unit/                         — модульные тесты
  data/                         — тестовые INI-файлы
  coverage/                     — инфраструктура анализа покрытия
```

## Сборка проекта

Для сборки используется CMake 3.10+, компилятор с поддержкой стандарта C++11.

### Сборка по умолчанию (включены тесты и покрытие):

```bash
rm -rf build
cmake -B build
cmake --build build
```

Все исполняемые файлы включая тесты и скрипт для проверки покрытия тестами помещаются в каталог:

`build/bin`

Файл конфигурации `ups_models.ini` копируется в каталог:

`build/bin/config`

### Сборка без тестов и покрытия:

```bash
rm -rf build
cmake -B build -DBUILD_TESTING=OFF -DBUILD_COVERAGE=OFF
cmake --build build
```

## Запуск эмулятора

SNMP-агент использует привилегированный порт 161, поэтому требуется запуск от имени root:

```bash
sudo ./build/bin/ups_emulator
```


## Проверка работы через SNMP

Пример запроса:

```bash
snmpget -v2c -c public localhost 1.3.6.1.4.1.318.1.1.1.1.1.1.0
```

Для выполнения запросов ко всем поддерживаемым OID можно использовать скрипт:

```bash
./run_snmpget.sh
```

## Тестирование

```bash
ctest --output-on-failure --test-dir build
```

## Покрытие тестами

Отчёт о покрытии можно получить командой:

```bash
./build/bin/run_coverage.sh
```

Результаты сохраняются в `tests/coverage`, и автоматически открывается браузер.


## Конфигурация моделей UPS

Файл `src/ups/ups_models.ini` содержит описания различных моделей UPS:

- OID-поля
- типы параметров
- наборы разрешённых значений
- правила интерпретации статусов

Формат позволяет расширять поддержку новых устройств без изменения исходного кода.
